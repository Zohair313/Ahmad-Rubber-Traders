# Ahmad Rubber Traders

Website for **Ahmad Rubber Traders** — wholesale supplier of dairy cow mats, EVA flooring sheets, and milking parlor mats in Lahore, Pakistan.

## What's inside

| Path | Purpose |
| --- | --- |
| `index.html` | Main static site (SEO metadata, JSON-LD LocalBusiness schema) |
| `css/` | Tokens, base styles and the main stylesheet |
| `js/app.js` | Site behaviour: language toggle (EN/UR), calculator, quote modal, WhatsApp CTAs |
| `data/` | Bilingual content (`en.json`, `ur.json`) and structured site data |
| `images/` | Product and context photography |
| `src/`, `dist/` | React/Vite version of the site and its production build |
| `OWNER-GUIDE.md`, `OWNER-GUIDE.ur.md` | How to update content (English / Urdu) |
| `DEVELOPER.md` | Technical notes for developers |

## Run the static site

Open `index.html` in a browser, or serve the folder locally:

```bash
npx serve .
```

## Run the React version

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # outputs to dist/
npm run preview  # preview the production build
```
